# Contributing to OmniChat

Thank you for your interest in contributing to OmniChat!

## Development Setup

1. **Android**: JDK 17, Android Studio with SDK 37
2. **Rust**: Stable Rust toolchain
3. **Server**: Rust + Docker (optional)

## Guidelines

- Follow the existing code style
- Write tests for new functionality
- Keep commits atomic and well-described
- Never commit secrets, signing keys, or private keys
- Never log message bodies or private keys
- Label all mock/stub security code as test-only
