# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in OmniChat, please report it responsibly.

**Email**: security@omnichat.org (when established)

**Do NOT**:
- Open a public GitHub issue for security vulnerabilities
- Share exploit details publicly before a fix is available

## Security Status

**Phase 1 (current)**: No production encryption implemented. All cryptographic operations use clearly-labeled test-only stubs. This build is NOT suitable for security-sensitive communication.
