# Security Policy

## Supported Versions

Only the latest `main` branch and the most recent stable release are actively supported for security updates.

| Version | Supported          |
| ------- | ------------------ |
| >= 0.1.x| :white_check_mark: |
| < 0.1.x | :x:                |

## Reporting a Vulnerability

We take the security of CiphrChat seriously. If you discover a security vulnerability, please do NOT file a public issue. 

Please report vulnerabilities via email:
- **Email:** security@ciphrchat.org
- **PGP Key:** `(Key to be published)`

### What to include
- A description of the vulnerability.
- Steps to reproduce the issue.
- Potential impact and attack vectors.

### Triage SLA
- We aim to acknowledge receipt of vulnerability reports within 48 hours.
- We will provide a status update or resolution timeline within 7 days.
- A public disclosure (CVE/Advisory) will be published once the patch is available to the community.
